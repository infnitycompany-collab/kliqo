Privacy Policy

Last updated · November 19, 2026

This policy covers this website, the Kliqo Recaps channels and Viral Studio, the private software the Kliqo Recaps team uses to publish and manage its own content. Viral Studio is not offered to the public: it is used only by the team, only with accounts the team owns.

This website

This site does not use cookies, analytics, advertising or any other tracking, and it does not ask for or store any personal information. It is hosted on GitHub Pages, which may keep standard server logs (such as IP addresses) for security, as described in the GitHub Privacy Statement. Fonts are loaded from Google Fonts.

What Viral Studio accesses

  • YouTube (Google), with the team's own permission: upload and schedule videos on the Kliqo Recaps channel, update the channel's branding, read public comments on Kliqo Recaps videos, reply to them, and hold spam or abusive comments for review, and read the channel's own statistics. It is used only with the Kliqo Recaps channel and never with anyone else's account.
  • Facebook, Instagram and TikTok (when connected): the same kind of access to the team's own Page and accounts only.

Information about viewers

When you comment on a Kliqo Recaps video, the comment text, your public display name and the comment's like count are read in order to answer questions and moderate spam. They are stored only on the team's own computer, used only for running the Kliqo Recaps channels, and never sold, shared or used for advertising. Replies may be drafted with the help of an AI model (Anthropic Claude), which receives the comment text for that purpose only.

We do not collect email addresses, phone numbers, locations or any data from people who do not interact with Kliqo Recaps content.

Google user data

Viral Studio's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access tokens are stored locally and are never shared.

Retention and deletion

Comment records are kept only as long as needed to run the channels. To have your comment data removed, or for any privacy question, send a message to Kliqo Recaps on Instagram or Facebook. The account owner can revoke Viral Studio's access at any time at myaccount.google.com/permissions.

Changes

If this policy changes, the new version will be posted on this page with a new date.
